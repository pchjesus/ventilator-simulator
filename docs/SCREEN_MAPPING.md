# Reference Screen Mapping

- Ppeak
- Pmean
- PEEP
- I:E
- fTOT
- VTE
- VE

- Pressure/Time
- Flow/Time
- 시간축
- mandatory/spontaneous breath 시각적 구분 가능성

## 하단 settings
- SIMV
- PC / Pi

- Frequency
- V-TRIG
- FiO2
- PEEP

## 주의
현재 사진만으로 정확한 제조사/기종과 모든 메뉴 동작을 확정하지 않는다.
현행 모델 사진과 공식 operator manual 확보 후 실제 UI specification을 확정한다.

# PB980 별도 학습실

기존 `index.html`은 유지하고 상단의 **새 학습실 열기** 링크로 `learn.html`에 진입한다. 새 화면 하단과 첫 화면 헤더의 **기존 시뮬레이터** 링크로 돌아간다.

## 확정 디자인과 화면 흐름

- A 시작 화면: 파랑 `#2854cc`, 흰색과 옅은 회색, 장비 그림, 학습 목적과 하나의 주 행동.
- 기초 학습 시작 → B 장비 탐색: 어두운 장비 배경 `#10232c`, 화면 위/가운데/아래의 세 영역을 선택하고 한 영역의 설명만 표시.
- 상단 장비 탐색 / 조작 연습 토글 → C 조작 연습: 초록 `#15745c`, 과제 목록과 선택한 과제, 한 번에 하나의 조작.
- 글꼴은 시스템의 한국어 산세리프를 사용하며 외부 폰트 요청이나 새 패키지 의존성이 없다.
- 공유 시안의 레이아웃을 유지하고 검토용 UI와 미동작 메뉴는 실제 이동·선택·연습으로 교체했다.

## 구현 범위

- 장비 탐색: 모니터 7항목, 설정 7항목, 파형 3종. 기존 `MONITOR_REFERENCE`, `PARAMETERS`, `DISPLAY_TERMS`를 사용한다.
- 조작 연습: PEEP 찾기, 변경 취소, 변경 적용 후 확인. 각 연습은 별도 `initialSettings()`로 시작한다.
- Pending 편집은 기존 `setting-editor.js`를 사용한다. 취소는 확정값을 바꾸지 않으며 적용은 확정값과 생성 파형에 반영된다.
- `waveform-model.js`의 16초 구간을 정지 화면으로 보여준다. 장비 화면 위쪽 숫자는 서로 독립적인 고정 예시로 파형·설정과 연동하지 않는다.
- 해시 경로 `#home`, `#explore`, `#practice`, `#practice-task`를 지원한다. 브라우저 뒤로/앞으로 이동이 가능하다.
- 탭 전환과 처음 화면 이동 시 선택·연습 상태를 메모리에 유지한다. 새로고침하면 초기화된다. 기존 앱의 설정·퀴즈·CASE 상태와 공유하거나 저장하지 않는다.
- 기존 학습용 설정 범위/단위를 재사용하며 실제 PB980 펌웨어, 실제 환자 생리 또는 임상 조작을 재현하지 않는다.

## 파일

- `learn.html`, `learning-room.css`: 별도 진입점과 스타일.
- `src/learning-room.js`: 화면 구성, 키보드/해시 이동, 기존 학습 자료와 연결.
- `src/learning-room-state.js`: 연습 세션, Pending/적용/취소 처리.
- `tests/learning-room.test.mjs`: 취소·확정의 분리, 연습 세션의 독립성, 잘못된 완료 방지, 설정/파형 연결 검사.

## 확인

`npm run check`와 `npm test`를 실행한다. 서버 실행 후 기존 홈의 새 학습실 링크 → A → B 영역/항목 선택 → C 세 과제 → B/C 전환 시 상태 유지 → 기존 시뮬레이터 복귀를 확인한다. 모바일에서는 토글과 설정 창의 가로 넘침 여부도 확인한다.

1. **현재 v0.5.0은 정상 실행·배포 검증된 기준 버전.** 먼저 현재 main SHA/Private 상태/CI 결과를 재확인하고 업로드된 기준 문서, 원본 코드/테스트를 읽는다. 이전 구현을 초기화하거나 덮어쓰지 않는다.

3. 사용자 결정 D1~D5를 다시 질문하지 않는다. 기존 UX에 실질적으로 새로운 중요한 선택이 생겼을 때만 장단점을 제시한다.

## 2. v0.5.1 — D1-A 가독성/접근성, 최초 착수용 상세 작업

### 2.1 사용자에게 보이는 최종 동작(기본 구현안)
- **PB980 원형 배치 그대로:** 7 모니터와 7 설정·3 파형·장비 테두리/기존 버튼/확정값 유지. 교육용 원형 기계 화면을 현대화된 대시보드로 바꾸지 않는다.
- **하나의 명확한 '큰 글씨로 보기' 진입 경로**를 기계 화면의 정보 영역 옆에 추가(7열 카드 각각에 새 조작 버튼을 강제로 넣지 않음). 펼쳐지는 별도 읽기 전용 모달/패널에서 선택 가능한 **'모니터 7개 / 설정 7개 / 파형 3개'** 세 범주를 제공. 필요하면 본래 7열 모니터 옆 외에도 학습 패널에서 같은 경로에 접근하게 할 수 있다. 접근 경로는 단일 콘텐츠 state를 공유해야 함.
- **고정 모니터**는 원래 순서·숫자·단위를 그대로 크게 표시하고, 각각 풀어 쓴 한국어 용어·'서로 독립 고정 예시' 태그를 함께 둔다. 이 숫자들을 '현재 한 환자의 실제 측정치'로 결합하지 않는다.
- **설정값**은 `PARAMETERS` + 현 `state`의 committed 수치를 크게 읽되 **입력/편집 불가**. '교육용 설정값' 태그, 단위, 기존 `?` 설명 접근 경로는 그대로. 예: PEEP 5.0 cmH₂O와 상단 고정 모니터 PEEP 5.8 cmH₂O가 서로 다른 자료임을 명시.
- **파형**은 Pressure/Flow/Volume의 한국어명·단위·생성 예시(실측 아님)·현재는 PEEP/Pi/PS/f/Ti만 파형에 반영된다는 안내; 기존 `#graph-*`와 일시정지/분석/격자 조작 유지. 확대 패널에서 **새 환자 지표를 계산하지 않는다**.
- 키보드: 호출 버튼 Enter/Space, 대화상자 Esc 닫기, 자연스러운 Tab 이동·호출 위치로 focus 반환. 바깥 클릭 닫기 구현 시 다른 기존 모달과 같은 단순한 원칙을 적용. 확대 중 장비를 숨기거나 breakpoint가 바뀌어도 focus가 사라지지 않게 점검.
- 320px 이상에서는 수치를 줄여 우겨넣기보다 교육용 읽기 패널을 세로로 스크롤·줄바꿈. 중요 값 잘림/가로 페이지 스크롤 금지. 단위/글자 최소 설계목표(새 주요 설명 14~16px)는 코딩 후 zoom/대비/육안으로 최종 조정; **WCAG 규정 최소 px 수치인 척 주장 금지**.
- 모든 읽기 UI는 **read-only**: 진입/탭 전환/닫기/viewport·모드 전환이 원래 state나 CASE/CORE/파형 재생 상태에 영향을 주지 않는다.

## 9. 버그·회귀 발생 시 대응

1. 증상·브라우저·viewport·커밋·정확한 재현 단계 확보.
2. 원인(예: CSS 우선순위, 숨겨진 element focus, 중복 렌더, source of truth 혼동, 배포 copy 누락) 분리.
3. 변경 범위 최소화, **그 버그를 재현하는 자동 테스트 먼저 추가**.
4. 수정 → 기능 테스트 → 영향을 받는 구 기능 회귀 → 시각 캡처 비교 → 문서 보고.
5. 같은 가설로 2회 수정 실패하면 **패치 누적 중지**, 코드·로그·상태흐름부터 재분석. 기존 구현/마지막 성공 main으로 복구 가능해야 함.
6. CI/실기기/사람 눈/의학 감수를 하나의 '전체 테스트 완료' 표현으로 뭉뚱그리지 않는다.

# v0.5.0 FINAL — 학생·교수자 사용성 파일럿 프로토콜 (시행 전 초안)

**상태 (2026-10-13):** 실제 참여자 모집·자료수집·분석·임상 감수 **미수행**. 본 문서는 수행 계획 및 기록 양식이며 연구윤리 승인이나 교육 효과의 입증을 의미하지 않는다. 필요 시 학교/기관 연구윤리심의·지도교수 검토를 먼저 받는다.

## 목적
1. 신규 간호학생이 도움 없이 '설정값 / 독립 고정 모니터 / 교육용 생성 파형 / CASE 가상 자료'를 구별하는지 평가한다.
2. 모바일/데스크톱에서 학습 개념 → 10문항 확인 → CASE 1개 적용 → 복습 경로를 스스로 찾아 수행할 수 있는지 관찰한다.
3. 교수가 학습목표·정답·오개념·디브리핑·임상 제한 사항을 이해하고 수업으로 연결할 수 있는지 평가한다.
4. 소프트웨어 UI 사용성과 교육적 이해도를 **별도 지표**로 구분한다.

## 참여·환경 (제안만)
- 초보 간호대학생 5–8명, 교육자 2–3명으로 시작하는 형성적 탐색 파일럿. 표본수는 통계적 유효성 검증용이 아니며 모집 시 실제 계획을 확정한다.
- PC (1440~960px), 본인 소유 스마트폰 등 실제 기기에서 각 1회 학습. 사전 지식 수준 기록은 익명/범주형으로만.
- 실환자 자료·학생 식별자·성적·의무기록·기기 생체 신호는 일절 수집하지 않는다. 참여·중단은 자유이며 기관 지침/동의 준수.

## 지표 해석과 다음 판정
- 탐색 성공률, 과제별 완료, 도움 요청, 오류·오조작, 화면 잘림, 복습 재진입, 오개념 유형을 기술통계·질적 분류로 요약하되 소표본 결과를 교육 효과 인과적 증거로 주장하지 않는다.
- **안전 우선 중대 결함**: 실제 측정 또는 임상 승인처럼 오인, 정답 사전 노출, 답안 재제출, 설정·CASE 상태 혼선, 필수 버튼 접근 실패.
- 발견→재현→원인 확인→패치→브라우저/실기기 회귀→기록. 같은 가설로 두 번 수정 실패 시 원인 분석부터 재시작.

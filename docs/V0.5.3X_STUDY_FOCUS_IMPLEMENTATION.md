# Ventilator Simulator v0.5.3.x — A1/B1 학습 집중형 UI 패치 계약

**승인:** 2026-10-15 · **이전 main:** `3356ff938c2a4842689271313ab39ced40266d8c` (v0.5.3) · **최종 목표:** v0.5.3.3.

## 적용 범위
1. **Patch 1 (0.5.3.1) — 읽기 위계:** 학습 영역의 제목/본문/선택지/출처 글꼴, 대비, 그룹 경계를 정돈한다. PB980 참고 장비는 변경하지 않는다.
2. **Patch 2 (0.5.3.2) — A1:** 기존 학습 집중 44:56·나란히·장비 집중 프리셋과 별개로, 701px 이상 ② 학습/기본 학습에서 **학습만 크게 보기/장비 함께 보기**를 제공한다. 전체 패널은 넓게, 읽기 본문 900px 이내, CORE LAB 1120px 이내. 700px 이하는 기존 장비 펼치기를 사용한다.
3. **Patch 3 (0.5.3.3) — B1:** 모바일 700px 이하에서는 기존 세 **설명서/패치 내역/설정 초기화** 버튼의 단일 DOM을 `details`로 접는다. CORE 개념/퀴즈/LAB/CASE 탐색과 한영 파형 이름·축, 완전히 일치하는 교육용 파형의 명시적인 오버랩 안내를 추가한다. 네 자료 출처 범례와 안전 경고는 보존한다.

## 데이터 및 상태 불변
- `studyOnly`는 `body.dataset.studyOnly`에만 반영하는 RAM UI 상태; 기존 `presentationMode`, `layoutPreset`, `studyArea`, `deviceExpanded`, `clinicalDeviceExpanded` 값을 덮어쓰지 않는다.
- `src/app.js` 기존 장비 `state`/`editState`, `waveformTime`, `inspectorActive`, 고정 모니터 7, CORE 6/10, CASE 4/12, LAB 3 선택·표본, 2개 비채점 행동 연습의 계산/정답은 그대로.
- 프레임워크/서버/저장소 없음. 화면 전환 및 빠른 이동은 동일 DOM/기존 상태 머신을 사용한다. `#lab-overlap-note`는 **그때 표시되는 생성 파형 배열이 동일할 때에만** 설명한다. FiO₂에 대한 실제 임상 반응 설명으로 사용하지 않는다.
- v0.5.4 D5-A(3 LAB × 예상/결과 2문항)는 이번 작업에 **포함되지 않음**. 추후 예상 문항 전 결과 사전 노출 제한을 `lab-overlap-note`에도 적용할 것.

## 회귀 보호 및 중단 기준
- `npm run check`, `npm test`, 기존 `browser-check.mjs`, `lab-browser-check.mjs`, 신규 `study-focus-browser-check.mjs`를 CI에서 수행.
- 기존 퀴즈/CASE 답변, LAB 선택, 설정 확정값/독립 모니터/파형 시간, 레이아웃 선택이 시각 모드 전환으로 소실되면 중단.
- 1440/1100/700/360/320px, 모바일 도구·dialog Escape·포커스 반환, 가로 넘침, 숨긴 장비 및 복귀, LAB 선 일치 안내와 그래프 크기 확인.
- 실제 학생 사용성/물리 스마트폰/스크린리더/임상 감수는 미실시로 구분. 코드/브라우저 PASS는 사람의 실제 가독성이나 임상적 적절성을 보증하지 않음.

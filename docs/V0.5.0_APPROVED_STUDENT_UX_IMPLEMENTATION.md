## 위험과 회귀 계약
1. 모든 UI/레이아웃 선택은 기존 **단일 DOM**을 이동·표시하는 방식이며 state를 복제하거나 설정/CASE를 리셋하지 않아야 한다.
2. 설정 편집의 원본/미확정/Pending·Accept/Cancel, 직접 숫자 입력, 길게 누르기, 전체·항목별 초기화는 재시험한다.
3. Pressure/Flow/Volume은 생성 파형이고, 상단 모니터 일곱 개는 **독립된 고정 표시 예시**로 값의 내부 일관성/한 환자의 동시 측정 데이터를 주장하지 않는다.
4. `core-quiz.js`의 문항/정답과 `preclinical-cases.js`의 문항/정답을 임의 변경하지 않는다. `CORE_QUIZ_VERSION="0.4.3"`, CASE `contentVersion="0.3.9"`는 앱 릴리스와 독립인 콘텐츠 검토 버전이다.
5. 복습에서 이전 응답만 읽기 전용으로 허용하고 **미응답 문항의 정답 키를 노출하지 않는다**.
6. 공개 가능한 웹앱 ZIP에는 실행 관련 정적 HTML/CSS/JS만 제공하고 교수자 답안 자료는 Private docs에 별도 보관한다. Private docs 자체는 보안/교수자 인증을 의미하지 않는다.

## 검증의 종류와 미완료 영역
- 자동 검사: Node 구문 및 단위, 실제 Chromium 브라우저, 각 너비 배치/오버플로, 키보드 인터랙션, 웹 ZIP 생성, GitHub Actions.
- 별도 수행해야 하는 것: 실제 스마트폰 사용, 전문 사용자 육안 QA, 초보 간호학생 사용성 파일럿, 교육자 학습 효율 평가, 임상/기기 전문가 및 병원 정책 감수.
- 실제 임상에서의 진단·치료·중재 판단이나 환자 결과 예측에 사용 불가.

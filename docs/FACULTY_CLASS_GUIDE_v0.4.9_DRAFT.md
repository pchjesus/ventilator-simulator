# Ventilator Simulator — 교수자용 수업 운영 자료 (v0.4.9 초안)

**대상:** 기계환기 기초를 처음 배우는 간호대학생. **문서 성격:** 교수자·개발자 참고용 초안. 전문가 임상 감수 및 실제 수업 사용성 검토 **미완료**.  
**배포 주의:** 정답·선택지 해설이 포함돼 학생의 사전 풀이 전에 공개하면 형성평가에 영향을 줄 수 있음. Private 저장소의 docs 문서이며, 웹앱 실행 ZIP에는 포함하지 않음. **암호화·접근권한 인증 기능은 아님.**

## 1. 목적과 범위
- 기계환기 화면의 설정값, 고정 모니터 예시, 단순화된 파형, CASE 가상 자료를 구별한다.
- 기초 용어와 관찰·판단·보고 원칙을 설명하고, 선택 후 오류 원인을 돌아보는 형성학습을 제공한다.
- 실제 PB980 조작 숙련도, 환자 생리 반응 계산, 인공호흡기 알람 발생/판정, 응급처치 수행능력, 임상 역량 인증을 평가하지 않는다.
- 화면의 7개 모니터 숫자는 각각 **독립적으로 고정된 표시 예시**이다. 하나의 실제 환자에서 동시에 측정된 일관된 자료가 아니다. FiO₂·V-TRIG는 파형에 연동되지 않으며 설정값으로 SpO₂·PaO₂·VTE를 계산하지 않는다.

## 2. 권장 진행 (시간은 교육 설계상 추정, 실측 아님)
| 단계 | 진행 | 권장 시간 |
|---|---|---|
| Prebriefing | 교육용 한계, 기기 화면과 임상 자료 구분, 실습학생 역할 확인 | 5분 |
| 핵심 개념 | 6개 카드, 기초 용어·심화 접기 | 10–12분 |
| 형성평가 | 10문항, 오답 이유 확인, 개념 재방문 | 10–15분 |
| CASE 01/02 | 사례당 3문항과 근거, 상황 자료 재열람 | 7분 / 8분 |
| Debriefing | 선택 이유·불확실성·보고 내용 점검 | 10분 |
총 **약 50–57분**의 권장 예시이며 학습자의 선행지식에 따라 조정한다. 1차 수업에서 한 사례만 선택하면 단축 가능.

## 3. 핵심 개념별 학습목표
| 개념 | 확인 목표 | 자주 발생하는 오개념 |
|---|---|---|
| PEEP | 호기말 양압의 의미와 산소화·순환 상태를 함께 관찰할 필요성 | PEEP를 높이면 모든 환자에게 반드시 이롭다 |
| FiO₂ | 공급 혼합가스 산소 비율과 SpO₂/PaO₂의 차이 | FiO₂ 40% = SpO₂ 40% |
| VTE | 호기 일회호흡량은 관찰 지표이며 PC 설정 압력과 별개임을 이해 | 설정 압력으로 VTE를 확정 |
| f / fTOT | 설정 강제호흡 빈도와 자발호흡을 포함한 총 호흡수 구분 | f와 fTOT는 항상 같거나 총 호흡수가 높으면 환기가 충분하다 |
| Ppeak / Pᵢ | 관찰 최고 기도압과 설정 흡기압 구분 | Ppeak만으로 높은 압력의 원인을 진단 |
| 환자 우선 사정 | 호흡 노력·흉곽 움직임·산소화 추세·기도와 회로 상태를 지도자와 함께 확인 | 화면 숫자만 보고 안정성 판단 또는 학생 독자적 기기 설정 변경 |

### 선행 약어
PBW(예측체중), Pplat(고원압), auto-PEEP(내인성 호기말 양압), ABGA(동맥혈가스분석), V-TRIG(유량 트리거)는 핵심 카드 아래 약어 풀이와 심화 접기에서 소개한다. 환자 모델이나 수치 계산이 구현됐다는 인상을 주지 않는다.

## 4. 핵심 개념 형성평가 정답표 (교수자용 · 정답 공개)

10문항 정답과 문항 ID는 v0.4.3 콘텐츠 검토 버전을 유지하며, 앱의 v0.4.9 런타임 버전과 다를 수 있다.

| 번호 | 문항 ID | 정답 | 학습자에게 설명할 이유 |
|---|---|---|---|
| 1 | peep-meaning | A | PEEP는 호기말 압력이며 효과는 환자 상황에 의존 |
| 2 | peep-circulation | B | SpO₂·혈압·호흡 양상을 함께 관찰 |
| 3 | fio2-setting | C | FiO₂는 공급 산소 농도 설정, 실측 산소포화도 아님 |
| 4 | fio2-measure | A | SpO₂와 PaO₂는 측정법과 단위가 다름 |
| 5 | vte-meaning | B | VTE는 호기 용적의 관찰 지표 |
| 6 | vte-pc | C | PC의 압력 설정으로 실제 VTE를 확정할 수 없음 |
| 7 | rate-distinction | A | SIMV 설정 f와 총 호흡수 fTOT는 다른 개념 |
| 8 | rate-static | B | 앱의 f-파형 관계와 고정 fTOT는 별도; **앱 동작 이해 문항** |
| 9 | ppeak-pi | C | Pᵢ 설정과 Ppeak 관찰은 다른 개념 |
| 10 | patient-first | B | 환자를 직접 관찰하고 지도자·의료진에 즉시 알림 |

**평가 해석:** 8번은 앱 작동의 제한을 이해했는지 확인하는 항목. 나머지는 간호 기초 개념 이해를 확인하지만, 어느 문항도 실제 임상 수행능력을 측정하거나 인증하지 않는다. 결과의 앱 이해/간호 개념 구분은 **문항의 근거 성격 분류**이지 검증된 심리측정 영역이 아니다.

## 5. CASE별 진행·정답·피드백

### CASE 01 · 기계환기 환자 첫 인수인계 (약 7분)
- **목표:** 설정과 측정의 차이(o1) → 환자·기도·회로 사정(o2) → 실습학생 역할·보고(o3).
- **상황:** 기계환기 장비를 지도간호사와 확인. 앱 상단 숫자는 실제 환자 측정값이 아니라 고정 예시.
- **정답:** 문항 1 **B**(고정 화면읽기 예시임을 인식), 문항 2 **B**(FiO₂로 실제 산소화 확인 불가), 문항 3 **C**(환자·기도·회로를 지도자와 함께 확인).
- **오개념:** 고정 예시를 실제 환자 측정값으로 오인 / FiO₂ 설정만으로 산소화 확정 / 환자 직접 사정 없이 숫자로 판단 / 학생 무단 설정 변경.
- **진행:** 상황 자료를 필요 시 다시 열고, 현재 목표를 읽고 답변. 이전 응답은 다음 단계에서 읽기만 가능. 완료 후 목표별 복습과 응답 이유·디브리핑 메모 확인.

### CASE 02 · 산소포화도 감소를 발견했을 때 (약 8분)
- **목표:** 수치와 임상 징후 동시 판단(o1) → 신속한 보고·도움 요청(o2) → 관찰·의사소통 우선(o3).
- **가상 상황:** SpO₂ 97→88%, 호흡수 18→30회/분, 호흡노력 변화. 이 수치는 앱 고정 모니터와 완전히 별개.
- **정답:** 문항 1 **A**(즉시 환자 및 신호 확인·도움 요청), 문항 2 **B**(환자·신호·실제 장비/기도/회로 종합 사정), 문항 3 **C**(변화 추세와 관찰을 구분하여 즉시 평가 요청).
- **오개념:** 단일 SpO₂ 숫자에만 의존 / 기다리며 도움 요청 지연 / 진단명 추정 / 무감독 기기 조작.
- **진행:** 이 자료는 응급처치 알고리즘이나 실제 기관 프로토콜을 대체하지 않음. 악화가 의심되는 실제 상황에서는 현장 안전 및 즉각적인 도움 요청이 우선.

**문항 근거 범위:** AARC (2024) 환자-인공호흡기 사정 지침은 직접 환자 사정과 압력·용적·PEEP·FiO₂ 평가 원칙을 제공한다. CASE 선택지의 구체적 배열, 실습학생 업무범위 및 상황별 정답은 교육 설계적 해석이 포함되어 있으며 기관별 임상 전문가 감수를 받지 않았다.

## 6. 디브리핑 질문
- 화면에서 **설정값**과 **고정 표시 예시**와 **실제 환자 측정 정보**와 **CASE의 가상 환자 수치**를 어떻게 나눠 설명할까?
- PEEP, FiO₂, VTE, fTOT, Ppeak 중 각각 무엇을 조절하고 무엇을 관찰하는가?
- CASE 01: 관찰하지 않은 항목이나 확인하지 못한 사실을 어떻게 보고할까?
- CASE 02: SpO₂ 감소와 호흡노력 증가를 지도자에게 어떤 순서로 전달할까? 무엇을 아직 모르는가?
- 오답에서 어떤 가정이 잘못됐고, 비슷한 실제 실습 상황에서 스스로 기기를 조작하지 않아야 할 이유는 무엇인가?

## 7. 교수자 사용 전 점검 / 승인되지 않은 사항
- [ ] PB980 현장 펌웨어·설치 옵션과 제조사 공식 매뉴얼의 일치 검토
- [ ] 6개 핵심 설명과 약어·개념 표현 정확성 확인
- [ ] 10개 형성평가 정답·오답 해설 검토
- [ ] CASE 01/02 문항 및 인과 추론의 교육 타당성 검토
- [ ] 실습학생 권한·병원별 응급 보고 절차에 맞는 표현 확인
- [ ] 초보 학생 대상 접근성·이해도·사용성 실제 파일럿 시행
- [ ] 수정 내용·검토자·날짜·근거를 별도 기록하고 승인 여부 확정

이 체크리스트는 계획이며 **현재 어느 항목도 승인 완료를 뜻하지 않는다.**

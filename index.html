학습 순서는 권장일 뿐이야. CORE·LAB·CASE는 자유롭게 이동할 수 있어. 새로고침이나 별도 학습실 이동 시 이 페이지 답안이 초기화될 수 있어.

학습 진도 확인 중

선택 학습 · 파형 비교 LAB

초기 설정과 실험 설정으로 만든 두 교육용 생성 파형을 동일한 축에 겹쳐 비교해. 현재 장비·퀴즈·CASE와 독립적인 학습이야.

2단계 · 기준/실험 생성 파형 관찰

기준 · 회색 점선 실험 · 강조 실선

현재 장비에 미반영 · 정적 교육용 생성 곡선(0–16초, 320표본) · 실제 환자의 SpO₂, PaO₂, VTE, fTOT 또는 혈역학 반응을 예측하지 않아. 임상 전문가 감수 전 교육 자료야.

5단계 · 내 학습 복습

CORE에서 틀린 개념, LAB에서 관찰한 생성 파형, CASE에서 아직 모르는 환자 정보를 돌아봐. 이것은 별도 채점이나 진도 완료 버튼이 아니야.

정답·해설은 각 문항에 답한 후 기존 결과 화면에서 확인해. 새로고침하거나 별도 학습실로 이동하면 이 페이지 기록은 유지되지 않아.

이 프로그램 상단 모니터는 실제 측정값이 아닌 고정 예시야. 환자 상태와 치료 반응을 계산하거나 예측하지 않아.
